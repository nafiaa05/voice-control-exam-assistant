# Voice-Control Exam Assistant

An AI-powered voice-controlled examination platform developed using Python Flask, HTML, CSS, and JavaScript.

## Features
- Voice-based exam navigation
- MCQ answering using speech recognition
- Text-to-speech question narration
- Tab-switch detection
- Camera monitoring
- Admin dashboard
- Real-time exam interaction

## Technologies Used
- Python Flask
- HTML
- CSS
- JavaScript
- Web Speech API
- JSON Storage

## Modules
- Student Management
- Admin Dashboard
- Voice Recognition
- Proctoring System
- Reporting Dashboard

## Future Enhancements
- AI-based proctoring
- Mobile application
- Offline voice recognition
- Multi-language support
